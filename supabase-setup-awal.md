## 1. Buat Akun Supabase

1. Buka website Supabase:

```txt
https://supabase.com
```

2. Klik `Start your project`.
3. Login menggunakan GitHub atau email.
4. Setelah masuk dashboard Supabase, klik `New project`.

## 2. Buat Project Baru

Isi form project:

- `Organization`: pilih organization milik kamu.
- `Project name`: contoh `besmartkids`.
- `Database Password`: buat password yang kuat dan simpan.
- `Region`: pilih region terdekat, misalnya `Singapore` jika tersedia.

Klik `Create new project`.

Tunggu sampai project selesai dibuat.

## 3. Ambil Supabase URL dan API Key

Setelah project selesai dibuat:

1. Masuk ke dashboard project Supabase.
2. Buka menu `Project Settings`.
3. Pilih `API`.

Catat bagian berikut:

- `Project URL`
- `anon public key`
- `service_role key`

Penjelasan:

- `Project URL` digunakan aplikasi untuk mengakses Supabase.
- `anon public key` aman dipakai di frontend.
- `service_role key` hanya boleh dipakai di server, jangan pernah ditaruh di frontend.

## 4. Buat File Environment

Di root project, buat file:

```txt
.env.local
```

Isi dengan format seperti ini:

```env
NEXT_PUBLIC_SUPABASE_URL=https://project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=isi_anon_public_key_di_sini
SUPABASE_SERVICE_ROLE_KEY=isi_service_role_key_di_sini
```

Ganti nilainya sesuai data dari Supabase.

Catatan penting:

- Variable dengan awalan `NEXT_PUBLIC_` bisa diakses browser.
- `SUPABASE_SERVICE_ROLE_KEY` hanya untuk server.
- Jangan upload `.env.local` ke GitHub.

## 5. Install Library Supabase

Jika project belum punya Supabase client, install package:

```bash
npm install @supabase/supabase-js
```

Jika menggunakan TypeScript dan Next.js, package ini sudah cukup.

## 6. Buat Client Supabase

Biasanya file Supabase client dibuat di:

```txt
src/lib/supabase.ts
```

Contoh konsep isi file:

```ts
import { createClient } from "@supabase/supabase-js";

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL!;
const supabaseAnonKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!;

export const supabase = createClient(supabaseUrl, supabaseAnonKey);
```

File ini digunakan untuk akses Supabase dari sisi client.

## 7. Buat Server Client Jika Dibutuhkan

Jika aplikasi butuh akses rahasia dari server, misalnya:

- Insert data admin.
- Baca semua data.
- Operasi bypass RLS.
- Sinkronisasi data default.

Buat client server menggunakan `service_role`.

Biasanya dibuat di:

```txt
src/lib/supabaseAdmin.ts
```

Contoh konsep:

```ts
import { createClient } from "@supabase/supabase-js";

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL!;
const serviceRoleKey = process.env.SUPABASE_SERVICE_ROLE_KEY!;

export const supabaseAdmin = createClient(supabaseUrl, serviceRoleKey);
```

Penting:

- File ini hanya boleh dipakai di API route/server.
- Jangan import file ini ke komponen client.

## 9. Pahami Row Level Security

Supabase memiliki fitur `Row Level Security` atau `RLS`.

Jika RLS aktif, data tidak bisa dibaca/ditulis sebelum ada policy.

Untuk aplikasi belajar sederhana, pilihan awal:

- Data kelas dan materi boleh dibaca publik.
- Soal boleh dibaca publik.
- Hanya admin yang boleh menambah/mengubah data.

Contoh mengaktifkan RLS:

```sql
alter table public.classes enable row level security;
alter table public.materials enable row level security;
alter table public.questions enable row level security;
```

Contoh policy baca publik:

```sql
create policy "Public can read classes"
on public.classes
for select
using (true);

create policy "Public can read materials"
on public.materials
for select
using (true);

create policy "Public can read questions"
on public.questions
for select
using (true);
```

Untuk insert/update/delete, sebaiknya lewat server API menggunakan `service_role`, bukan langsung dari browser.

## 10. Tes Koneksi dari Aplikasi

Buat test sederhana dari server atau halaman development:

```ts
const { data, error } = await supabase.from("classes").select("*");
```

Jika berhasil:

- `error` bernilai `null`.
- `data` berisi array.

Jika gagal, cek:

- Apakah `.env.local` sudah benar.
- Apakah server dev sudah direstart.
- Apakah tabel sudah dibuat.
- Apakah RLS/policy mengizinkan select.
- Apakah nama tabel benar.

## 23. Buat API untuk Mengambil Kelas

Setelah tabel siap, buat API untuk membaca data kelas.

Contoh lokasi file:

```txt
src/app/api/classes/route.ts
```

Contoh isi:

```ts
import { NextResponse } from "next/server";
import { supabase } from "@/lib/supabase";

export async function GET() {
  const { data, error } = await supabase
    .from("classes")
    .select("*")
    .eq("is_active", true)
    .order("grade_level", { ascending: true });

  if (error) {
    return NextResponse.json(
      {
        success: false,
        message: "Gagal mengambil data kelas",
        error: error.message,
      },
      { status: 500 },
    );
  }

  return NextResponse.json({
    success: true,
    data,
  });
}
```

## 24. Buat API untuk Mengambil Materi Berdasarkan Kelas

Contoh lokasi file:

```txt
src/app/api/classes/[gradeLevel]/materials/route.ts
```

Contoh isi untuk Next.js App Router versi terbaru:

```ts
import { NextResponse } from "next/server";
import { supabase } from "@/lib/supabase";

export async function GET(
  request: Request,
  context: { params: Promise<{ gradeLevel: string }> },
) {
  const { gradeLevel } = await context.params;
  const grade = Number(gradeLevel);

  if (!Number.isFinite(grade)) {
    return NextResponse.json(
      {
        success: false,
        message: "Grade level tidak valid",
        received: gradeLevel,
      },
      { status: 400 },
    );
  }

  const { data, error } = await supabase
    .from("materials")
    .select("*, classes!inner(grade_level)")
    .eq("classes.grade_level", grade)
    .eq("is_active", true)
    .order("sort_order", { ascending: true });

  if (error) {
    return NextResponse.json(
      {
        success: false,
        message: "Gagal mengambil data materi",
        error: error.message,
      },
      { status: 500 },
    );
  }

  return NextResponse.json({
    success: true,
    data,
  });
}
```

Catatan penting:

- Angka pada `/api/classes/1/materials` adalah `gradeLevel`, bukan `id` tabel `classes`.
- `/api/classes/1/materials` berarti mengambil materi untuk `Kelas 1`.
- Jika folder route kamu bernama `[gradeLevel]`, maka ambil nilainya dari `gradeLevel`.
- Jika folder route kamu bernama `[id]`, maka ambil nilainya dari `id`.
- Untuk Next.js versi baru, `params` sering perlu di-`await` seperti contoh di atas.

## 25. Buat API untuk Mengambil Soal Berdasarkan Materi

Contoh lokasi file:

```txt
src/app/api/materials/[materialId]/questions/route.ts
```

Contoh isi untuk Next.js App Router versi terbaru:

```ts
import { NextResponse } from "next/server";
import { supabase } from "@/lib/supabase";

export async function GET(
  request: Request,
  context: { params: Promise<{ materialId: string }> },
) {
  const { materialId } = await context.params;
  const id = Number(materialId);

  if (!Number.isFinite(id)) {
    return NextResponse.json(
      {
        success: false,
        message: "Material ID tidak valid",
        received: materialId,
      },
      { status: 400 },
    );
  }

  const { data, error } = await supabase
    .from("questions")
    .select("*")
    .eq("material_id", id)
    .eq("is_active", true)
    .order("sort_order", { ascending: true });

  if (error) {
    return NextResponse.json(
      {
        success: false,
        message: "Gagal mengambil data soal",
        error: error.message,
      },
      { status: 500 },
    );
  }

  return NextResponse.json({
    success: true,
    data,
  });
}
```

Catatan penting:

- Angka pada `/api/materials/1/questions` adalah `materialId`.
- `materialId` mengacu ke kolom `id` pada tabel `materials`.
- Jadi `/api/materials/1/questions` berarti mengambil soal untuk materi dengan `id = 1`.

```ts
import { supabase } from "@/lib/supabase";

export async function GET(
  request: Request,
  context: { params: Promise<{ materialId: string }> },
) {
  const { materialId } = await context.params;
  const id = Number(materialId);

  if (!Number.isFinite(id)) {
    return NextResponse.json(
      {
        success: false,
        message: "Material ID tidak valid",
        received: materialId,
      },
      { status: 400 },
    );
  }

  const { data, error } = await supabase
    .from("materials")
    .select("*")
    .eq("id", id)
    .eq("is_active", true)
    .single();

  if (error) {
    return NextResponse.json(
      {
        success: false,
        message: "Gagal mengambil detail materi",
        error: error.message,
      },
      { status: 500 },
    );
  }

  return NextResponse.json({
    success: true,
    data,
  });
}
```

```tsx
function getYoutubeEmbedUrl(url: string | null) {
  if (!url) return null;

  try {
    const parsedUrl = new URL(url);

    if (parsedUrl.hostname.includes("youtu.be")) {
      const videoId = parsedUrl.pathname.replace("/", "");
      return `https://www.youtube.com/embed/${videoId}`;
    }

    if (parsedUrl.searchParams.has("v")) {
      return `https://www.youtube.com/embed/${parsedUrl.searchParams.get("v")}`;
    }

    if (parsedUrl.pathname.includes("/embed/")) {
      return url;
    }

    return null;
  } catch {
    return null;
  }
}
```

```tsx
"use client";

import Link from "next/link";
import { useMemo, useState } from "react";
import type { QuestionItem } from "@/types/learning";

type QuizClientProps = {
  materialId: string;
  questions: QuestionItem[];
};

export default function QuizClient({ materialId, questions }: QuizClientProps) {
  const [answers, setAnswers] = useState<Record<number, string>>({});
  const [submitted, setSubmitted] = useState(false);

  const answeredCount = Object.keys(answers).length;
  const allAnswered =
    questions.length > 0 && answeredCount === questions.length;

  const score = useMemo(() => {
    return questions.reduce((total, question) => {
      const userAnswer = answers[question.id];
      return userAnswer === question.correct_answer ? total + 1 : total;
    }, 0);
  }, [answers, questions]);

  function handleSelect(questionId: number, value: string) {
    if (submitted) return;

    setAnswers((current) => ({
      ...current,
      [questionId]: value,
    }));
  }

  function handleSubmit() {
    if (!allAnswered) return;
    setSubmitted(true);
  }

  return (
    <main className="min-h-screen bg-[#eefbf3] px-4 py-8">
      <section className="mx-auto max-w-4xl">
        <div className="mb-5 flex flex-wrap items-center justify-between gap-3">

            href={`/materi/${materialId}`}
            className="rounded-md bg-white px-4 py-2 text-sm font-semibold text-emerald-700 shadow-sm hover:bg-emerald-50"
          >
            Kembali ke Materi
          </Link>

          <div className="rounded-md bg-white px-4 py-2 text-sm font-semibold text-slate-700 shadow-sm">
            Terjawab {answeredCount} dari {questions.length}
          </div>
        </div>

        <div className="mb-6 rounded-lg bg-white p-6 shadow-sm">
          <p className="text-sm font-semibold uppercase tracking-wide text-emerald-700">
            Latihan Soal
          </p>
          <h1 className="mt-2 text-3xl font-bold text-slate-900">
            Kerjakan Semua Soal
          </h1>
          <p className="mt-3 text-slate-600">
            Pilih jawaban terbaik. Setelah semua soal dijawab, tombol submit
            akan aktif.
          </p>
        </div>

        {questions.length === 0 ? (
          <div className="rounded-lg bg-white p-6 text-slate-600 shadow-sm">
            Soal latihan untuk materi ini belum tersedia.
          </div>
        ) : (
          <div className="space-y-4">
            {questions.map((question, index) => {
              const userAnswer = answers[question.id];
              const isCorrect =
                submitted && userAnswer === question.correct_answer;
              const isWrong =
                submitted && userAnswer !== question.correct_answer;

              return (
                <article
                  key={question.id}
                  className={[
                    "rounded-lg border bg-white p-5 shadow-sm",
                    isCorrect ? "border-emerald-300 bg-emerald-50" : "",
                    isWrong ? "border-red-300 bg-red-50" : "",
                  ].join(" ")}
                >
                  <div className="mb-4 flex items-start gap-3">
                    <div className="flex h-8 w-8 shrink-0 items-center justify-center rounded-md bg-emerald-600 text-sm font-bold text-white">
                      {index + 1}
                    </div>
                    <div>
                      <p className="font-semibold text-slate-900">
                        {question.question}
                      </p>
                      {question.image_url ? (
                        <img
                          src={question.image_url}
                          alt={`Gambar soal nomor ${index + 1}`}
                          className="mt-3 max-h-72 rounded-md border object-contain"
                        />
                      ) : null}
                    </div>
                  </div>

                  {question.type === "pilihan_ganda" && question.options ? (
                    <div className="space-y-2">
                      {question.options.map((option) => {
                        const selected = userAnswer === option;
                        const correctOption =
                          submitted && option === question.correct_answer;
                        const wrongOption =
                          submitted &&
                          selected &&
                          option !== question.correct_answer;

                        return (
                          <button
                            key={option}
                            type="button"
                            onClick={() => handleSelect(question.id, option)}
                            className={[
                              "w-full rounded-md border px-4 py-3 text-left text-sm transition",
                              selected
                                ? "border-emerald-600 bg-emerald-50"
                                : "border-slate-200 bg-white hover:bg-slate-50",
                              correctOption
                                ? "border-emerald-700 bg-emerald-200 text-emerald-950"
                                : "",
                              wrongOption
                                ? "border-red-700 bg-red-200 text-red-950"
                                : "",
                            ].join(" ")}
                          >
                            {option}
                          </button>
                        );
                      })}
                    </div>
                  ) : (
                    <input
                      type="text"
                      disabled={submitted}
                      value={userAnswer ?? ""}
                      onChange={(event) =>
                        handleSelect(question.id, event.target.value)
                      }
                      placeholder="Tulis jawaban"
                      className="w-full rounded-md border border-slate-200 px-4 py-3 text-sm outline-none focus:border-emerald-600"
                    />
                  )}

                  {submitted ? (
                    <div className="mt-4 rounded-md bg-white p-4 text-sm text-slate-700">
                      <p
                        className={
                          isCorrect
                            ? "font-bold text-emerald-700"
                            : "font-bold text-red-700"
                        }
                      >
                        {isCorrect
                          ? "Jawaban sudah benar."
                          : "Jawaban belum tepat."}

                      {question.explanation ? (
                        <p className="mt-2 whitespace-pre-line">
                          {question.explanation}
                        </p>
                      ) : null}
                    </div>
                  ) : null}
                </article>
              );
            })}

            <div className="sticky bottom-4 rounded-lg bg-white p-4 shadow-lg">
              {submitted ? (
                <div className="flex flex-wrap items-center justify-between gap-3">
                  <p className="font-bold text-slate-900">
                    Skor kamu: {score} dari {questions.length}
                  </p>
                  <button
                    type="button"
                    onClick={() => {
                      setAnswers({});
                      setSubmitted(false);
                    }}
                    className="rounded-md bg-emerald-600 px-5 py-3 text-sm font-bold text-white hover:bg-emerald-700"
                  >
                    Ulangi Latihan
                  </button>
                </div>
              ) : (
                <button
                  type="button"
                  disabled={!allAnswered}
                  onClick={handleSubmit}
                  className="w-full rounded-md bg-emerald-600 px-5 py-3 text-sm font-bold text-white hover:bg-emerald-700 disabled:cursor-not-allowed disabled:bg-slate-300"
                >
                  Submit Jawaban
                </button>
              )}
            </div>
          </div>
        )}
      </section>
    </main>
  );
}
```

Catatan:

- Untuk awal, pilihan ganda sudah paling stabil.
- Essay sederhana tetap bisa dipakai, tetapi koreksi masih harus exact match.
- Multipart sebaiknya dibuat setelah pilihan ganda dan essay stabil.

## 36. Buat Validasi Data Soal

Sebelum soal ditampilkan ke siswa, pastikan data soal valid.

Checklist soal pilihan ganda:

- Opsi jawaban minimal 2.

Implementasi validator:

Lokasi file:

```txt

```

Isi file:

```ts
import type { QuestionItem } from "@/types/learning";

export function validateQuestion(question: QuestionItem) {
  const errors: string[] = [];

  if (!question.question || question.question.trim().length === 0) {
    errors.push("Pertanyaan kosong");
  }

  if (!question.type) {
    errors.push("Tipe soal kosong");
  }

  if (question.type === "pilihan_ganda") {
    if (!Array.isArray(question.options) || question.options.length < 2) {
      errors.push("Pilihan ganda minimal memiliki 2 opsi");
    }

    if (!question.correct_answer) {
      errors.push("Jawaban benar kosong");
    }

    if (
      Array.isArray(question.options) &&
      question.correct_answer &&
      !question.options.includes(question.correct_answer)
    ) {
      errors.push("Jawaban benar tidak ada di dalam opsi");
    }
  }

  if (question.type === "essay") {
    if (!question.correct_answer) {
      errors.push("Jawaban essay kosong");
    }
  }

  if (!question.explanation || question.explanation.trim().length === 0) {
    errors.push("Pembahasan kosong");
  }

  return {
    valid: errors.length === 0,
    errors,
  };
}
```

Contoh penggunaan di halaman latihan:

```ts
import { validateQuestion } from "@/lib/validate-question";

const validQuestions = questions.filter((question) => {
  return validateQuestion(question).valid;
});
```

Untuk tahap awal, tampilkan hanya soal yang valid agar halaman latihan tidak error.

```tsx
};

function renderPower(text: string) {
  return text.split(/(\d+\^\d+)/g).map((part, index) => {
    const match = part.match(/^(\d+)\^(\d+)$/);

    if (!match) return <span key={index}>{part}</span>;

    return (
      <span key={index}>
        {match[1]}
        <sup>{match[2]}</sup>
      </span>
    );
  });
}

export default function MathText({ text }: MathTextProps) {
  if (text.includes("sqrt(")) {
    const parts = text.split(/sqrt\((.*?)\)/g);

    return (
      <span>
        {parts.map((part, index) => {
          if (index % 2 === 1) {
            return (
              <span key={index} className="inline-flex items-start">
                <span className="text-lg">√</span>
                <span className="border-t border-current px-1">{part}</span>
              </span>
            );
          }

          return <span key={index}>{renderPower(part)}</span>;
        })}
      </span>
    );
  }

  return <span>{renderPower(text)}</span>;
}
```

## 52. Pastikan Nama Folder Route Sesuai dengan Params

Jika file berada di:


Nama folder dinamis harus sama dengan nama property yang dibaca dari `params`.

## 56. Pastikan Relasi `materials` ke `classes` Benar

Query ini:

```ts
.select("*, classes!inner(grade_level)")
```

membutuhkan relasi foreign key dari:

```txt
materials.class_id
```

ke:

```txt
classes.id
```

Cek apakah `materials.class_id` sudah ada:

```sql
select column_name
from information_schema.columns
where table_schema = 'public'
and table_name = 'materials'
and column_name = 'class_id';
```

Jika belum ada, tambahkan:

```sql
alter table public.materials
add column class_id bigint;
```

Tambahkan foreign key:

```sql
alter table public.materials
add constraint materials_class_id_fkey
foreign key (class_id)
references public.classes(id)
on delete cascade;
```

Catatan:

- Jika sudah ada constraint dengan nama yang sama, query ini akan error.
- Jika error karena constraint sudah ada, berarti tidak perlu ditambahkan lagi.
